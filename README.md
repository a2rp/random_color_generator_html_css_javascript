# Random Color Generator

A lightweight HTML, CSS, and JavaScript tool for generating random colors and viewing their Hexadecimal, RGB, RGBA, and HSL values.

## Features

- Generate a fresh random color with one click.
- View common CSS color formats.
- Copy any generated value.
- Responsive layout with local branding assets and social sharing metadata.

## Tech stack

HTML, CSS, Sass source, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.
